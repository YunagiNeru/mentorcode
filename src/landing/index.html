Mentor Code

サーバートークンを提供された開発者だけが使える、招待制AIコーディングアプリです。 コードを送る前にローカルで検査し、秘密情報をマスクし、実装の理解とレビューを優先して開発を前に進めます。

Designed For Understanding

速さだけでなく、説明できる開発へ。

Mentor Codeは、AIに丸投げする前提のツールではありません。 実装計画、段階式ヒント、差分レビュー、送信前プレビューを一つの流れにまとめ、変更の理由とリスクを開発者が追える状態にします。

Guided Work

段階式ヒントで理解を残す

答えを急がず、ヒント量を調整しながら要件整理、読むべきファイル、検証観点まで分解します。

Repository Context

関連ファイルを送信前に可視化

ワークスペース構成を読み取り、送信候補、除外ファイル、マスク内容を確認してからApp Serverへ渡します。

Review Loop

差分レビューで学習点まで返す

要件充足、例外、セキュリティ、保守性、次に確認すべき観点を整理し、レビューを作業の終点にしません。

Positioning

主要AIエージェントの良さを、招待制と安全設計に寄せる。

近年のAIコーディングLPは、IDE統合、並列実行、タスク可視化、レビュー待ち状態を強く打ち出しています。 Mentor Codeはその体験を参考にしつつ、利用権限と送信前保護を最初から中核に置きます。

一般的なAIコーディング体験

  • 素早い提案と自動化を前面に出す
  • IDE、CLI、クラウド作業を横断する
  • タスク進行やレビュー待ちを可視化する

Mentor Code

  • サーバートークンを持つ招待ユーザーに限定
  • ローカル検査とマスキングを送信前に実施
  • 実装計画、ヒント、レビューで理解可能性を重視

Privacy Guard

外へ送る前に、ローカルで止める。

リポジトリ本文、設定、ログには秘密情報が混ざります。 Mentor Codeは送信前プレビューを標準化し、マスク済みContextPackageだけを承認後にApp Serverへ渡します。

01

Workspace Scan

許可された範囲のファイル構成を読み、除外対象と送信候補を分離します。

02

Local Masking

秘密情報、個人情報、内部情報をローカルで検出し、ブロックまたはマスクします。

03

Preview Approval

送信対象、除外理由、マスク箇所を確認し、承認後だけサーバーに送ります。

04

Server Recheck

App Server側でも未マスクの危険情報が残っていないか再検査します。

Workflow

招待からレビューまで、権限を細く保つ。

  1. 1

    管理者がサーバートークンを発行

    利用者は提供されたトークンをVS Code拡張へ設定します。トークンがない環境ではApp Serverを利用できません。

  2. 2

    課題と参照ファイルを明示

    必要なファイルを選び、ローカル検査を通過したContextだけを送信前プレビューに進めます。

  3. 3

    計画、ヒント、レビューを受け取る

    AI応答は実装の理由、影響範囲、失敗条件、検証観点を中心に返し、理解の負債を増やしません。

Invite Access / Open Source

招待環境を使う。あるいは、自分で運用する。

招待ユーザーは、管理者から受け取ったApp Server URLとサーバートークンですぐに利用できます。 OSSとしてソースコードを取得し、自分の環境にApp Serverをセルフホストすることもできます。

VS Code拡張をダウンロード GitHubからソースを入手

GitHubのセルフホスト手順では、App Serverの構築、初期管理者の作成、VS Code拡張の接続まで確認できます。

必要なもの

招待サーバートークン、App Server URL、VS Code拡張

守るもの

秘密情報、個人情報、内部URL、送信禁止パス

確認するもの

マスク内容、影響範囲、テスト観点、ロールバック

  1. 1

    このページから最新の .vsix をダウンロードします。

  2. 2

    VS Codeの拡張機能画面で ... を開き、Install from VSIX... を選択します。

  3. 3

    ダウンロードしたVSIXを選択し、インストール後にVS Codeを再読み込みします。

  4. 4

    Mentor Codeの設定でサーバートークンを入力し、有効表示を確認します。

FAQ

利用前に確認すべきこと。

Mentor Codeは誰でも使えますか？

いいえ。管理者からサーバートークンを提供された招待ユーザーだけが利用できます。

秘密情報はそのままApp Serverへ送られますか？

送信前にローカルで検出、除外、マスクを行います。App Server側でも安全性を再検査します。

セルフホスト環境でも使えますか？

はい。管理者が用意したApp Server URLとサーバートークンをVS Code拡張に設定して利用します。
